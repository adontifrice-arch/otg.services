# otg.services

Site public Off The Grid : GED, applications métier, IA souveraine, expertise IBM FileNet et CP4BA.

## Aperçu local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```
npx --yes serve .
```

## Contenu

- `index.html` — Accueil
- `ged.html` — OTG Documents
- `integrations.html` — Intégrations aux GED du marché
- `ibm-filenet.html` — IBM FileNet et CP4BA
- `applications.html` — Applications métier
- `ia-souveraine.html` — IA souveraine
- `devis.html` — Demande de devis
- `assets/` — Styles, script, marque

Pas de prix ni de formules : chaque projet est chiffré sur devis.
